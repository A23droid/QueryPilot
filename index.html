Security & Policy Control

ArmorIQ Zero-Trust Governance

When autonomous AI agents interact with your database, ArmorIQ validates cryptographic CSRG intent tokens to approve read-only inspections while blocking destructive schema mutations.

Cryptographic Intent Verification

Autonomous agents can easily generate dangerous DDL or unrestricted table locks. QueryPilot embeds ArmorIQ at the control plane to enforce strict zero-trust boundaries.

CSRG Intent Tokens

Mints short-lived (300s TTL) cryptographic tokens required for all tool invocations.

Read-Only Tool Authorization

Enforces policy allowing explain_query and analyze_plan while denying raw writes.

Audit Logging & Replay Trail

Every decision is signed and verifiable via the ArmorIQ customer proxy.

Config: armoriq.yaml · Policy Engine Active
armoriq.yaml 
version: v1
identity:
  api_key: $ARMORIQ_API_KEY
  user_id: querypilot-user
  agent_id: querypilot

environment: sandbox
proxy:
  url: https://customer-proxy.armoriq.ai
  timeout: 30

mcp_servers:
  - id: querypilot-db
    auth:
      type: bearer
      token: $QUERY_PILOT_MCP_TOKEN

# Zero-trust principle: allow inspection, block mutation
policy:
  allow:
    - querypilot-db.explain_query
  deny: []

intent:
  ttl_seconds: 300
  require_csrg: true
Agentic Tooling

Model Context Protocol Server

QueryPilot operates an MCP server over Streamable HTTP on port :3333. Seamlessly connect Claude Desktop, Cursor, or autonomous agents to analyze database plans.

Tool: explain_query

Safe Plan Extraction

Accepts raw SQL queries, runs EXPLAIN (FORMAT JSON) without executing data mutations, and returns parsed AST metrics.

Tool: analyze_plan

Anti-Pattern Detection

Scans the execution tree for high-cost sequential scans, cartesian products, and missing foreign key join indexes.

Tool: suggest_indexes

Deterministic DDL

Cross-references table statistics and schema to output exact CREATE INDEX CONCURRENTLY recommendations.
