What it does

Six commands that cover the full lifecycle from query inspection to CI regression prevention.

🔍

Analyze

Run EXPLAIN (FORMAT JSON), render a color-coded plan tree, and surface findings like Seq Scan, Sort, and high-cost nodes.

🛠️

Optimize

Numbered action items with copy-paste SQL suggestions. Optional LLM rewrites via Groq/Gemini/OpenAI.

⏱️

Benchmark

Run queries N times and report min/mean/p50/p95/p99/max latency.

📸

Baseline

Snapshot the current plan as a "known good" reference for future comparisons.

⚖️

Compare

Diff current plan vs baseline. Flags regressions above a threshold, exits non-zero for CI.

🧩

Prisma

Parse .prisma schemas, map models to SQL, generate CREATE TABLE and SELECT queries.

Commands

Install globally with npm link or run via npx tsx src/index.ts <cmd>.

CommandPurpose
qp analyze <file>EXPLAIN plan + findings
qp optimize <file> [--suggest]Action items + optional LLM rewrites
qp benchmark <file> [--runs N]Latency percentiles (default 10 runs)
qp baseline save <file> [--ref label]Save plan snapshot
qp compare <file> [--threshold pct]Diff vs baseline, exit non-zero on regression
qp prisma <file> [--sql] [--analyze model]Parse Prisma schema, generate SQL
qp report <file>Markdown summary for PR comments

Install

Requires Node.js 18+ and PostgreSQL. LLM and ArmorIQ are optional.

setup 
$ git clone https://github.com/quwrof00/QueryPilot.git
$ cd QueryPilot && npm install
$ cp .env.example .env  # edit DATABASE_URL (and optional keys)
$ npm run build && npm link
$ qp --version
