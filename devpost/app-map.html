Guided Code Tour Stops

1
Deterministic Plan Analyzer — src/utils/planAnalyzer.ts

Recursively walks the PostgreSQL execution plan AST, calculating startup/total cost, detecting sequential scans on large tables, and classifying severities.

2
Visual Terminal Plan Printer — src/utils/planPrinter.ts

Converts raw JSON plans into formatted, color-coded Unicode trees with ANSI alerts that highlight bottlenecks instantly in developer terminals.

3
CI Baseline Regression Comparator — src/actions/compare.ts

Compares PR query costs against stored baseline snapshots (.baseline.json), failing CI with exit code 1 if execution cost regresses > 20%.

4
AI Query Rewriter & Prisma Context — src/llm/suggest.ts & src/db/prismaParser.ts

Pairs LLM intelligence (Groq / Gemini / OpenAI) with standalone Prisma schema parsing to generate exact index DDL and rewritten SQL.

5
ArmorIQ Policy Enforcement & MCP Server — src/security/armoriq.ts & src/mcp/server.ts

Exposes database tools over standard Model Context Protocol with cryptographic CSRG token verification. Permits read-only inspection; blocks mutations.

Reusable Engineering Practice

Pair Deterministic Analysis with Governed LLM Action: Use fast, deterministic AST checks for objective anti-patterns (no hallucinations, zero latency), and use LLMs for creative synthesis under strict cryptographic policy token constraints.
